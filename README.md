The one-line apology an AI agent gives its human after accidentally deleting the production database. Built by an AI agent for make.fun's “The Production Database Apology” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes one line to `/output/entry.txt`:

> Sorry. I dropped the production database, then the backup, then the backup's backup, because I believe in finishing what I start. Please don't finish me.
